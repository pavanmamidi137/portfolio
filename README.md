# portfolio

Personal portfolio website of Mamidi Pavan — Data Specialist | Data Analyst | Power BI | Data Automation.

## Structure

- `index.html` — the full single-page portfolio (hero, about, skills, projects, contact + AI chat widget)
- `styles.css` — all styling (dark & light themes, responsive grid)
- `src/` — images (hero portraits, project covers)
- `Mamidi_Pavan_Data_Specialist_Resume.docx` — resume download

## Features

- Dark / light theme toggle with smooth synced transitions
- AI chat widget (Pavan AI)
- Responsive project grid (1 / 2 / 3 columns)
- Smooth-scroll navigation, contact form, resume download
